# Οχήματα - Πρακτική εγκατάσταση

Αυτός ο φάκελος είναι η καθαρή έκδοση που προτείνεται να ανέβει στο GitHub.

## Τι ανεβαίνει στο GitHub

Ανεβαίνουν τα αρχεία της εφαρμογής:

- `oximata.py`
- `database.py`
- `config.py`
- `ui_components.py`
- `utils.py`
- `requirements.txt`
- `requirements-build.txt`
- `Oximata.spec`
- `BUILD_EXE.bat`
- `RUN_FROM_SOURCE.bat`
- `CREATE_DESKTOP_SHORTCUT.ps1`

Δεν ανεβαίνει ο φάκελος `data`, γιατί εκεί αποθηκεύονται τα πραγματικά στοιχεία της δουλειάς: βάση, οδηγοί, οχήματα, κινήσεις, PDF, logs και backups.

## Στον υπολογιστή της δουλειάς

Η πιο απλή ροή είναι:

1. Κατεβάζεις το repo από GitHub.
2. Τρέχεις μία φορά το `SETUP_WORK_PC.bat`.
3. Ο συνάδελφος ανοίγει την εφαρμογή από το εικονίδιο `Οχήματα` στην Επιφάνεια Εργασίας.

Μετά την πρώτη εκκίνηση, η εφαρμογή θα δημιουργήσει αυτόματα τον φάκελο `data` και τη βάση `data\oximata.db`.

## Καθημερινή χρήση

Ο συνάδελφος δεν χρειάζεται Git, Python ή εντολές. Χρειάζεται μόνο διπλό κλικ στο εικονίδιο.

Τα οχήματα και οι οδηγοί που θα καταχωρηθούν μένουν στον ίδιο υπολογιστή, μέσα στο `data\oximata.db`.

## Backup

Ο φάκελος που έχει αξία για αντίγραφο ασφαλείας είναι:

`data`

Αν μεταφερθεί η εφαρμογή σε άλλον υπολογιστή, αντιγράφεις και τον φάκελο `data` μαζί με το `Oximata.exe`.

## Σημαντικό

Μην ανεβάσεις ποτέ στο GitHub τον φάκελο `data`, αν περιέχει πραγματικά στοιχεία οδηγών ή οχημάτων.
